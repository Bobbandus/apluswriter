# A+ Toolkit

Plan, Shoot och Live: verktygen för A+ Studios produktioner.

Allt ligger i mappen [`aplustoolkit/`](aplustoolkit). Börja med
[`aplustoolkit/README.md`](aplustoolkit/README.md) och `aplustoolkit/ideas.txt`.

```bash
cd aplustoolkit
npm install
npm run dev
```

Nycklar (`api.txt`, `.env.local`) hålls utanför git. Se `.gitignore`.
